This addendum replaces obsolete endpoint, port, tool, and test-count descriptions in the design-phase plan. TESTING.md remains the operational source of truth.

Automated Test Inventory

LayerTools and current scope
Backend unitJUnit 5 and Mockito: JWT behavior, cache behavior, DTO mapping, asset-management rules, and metal validation.
Backend integrationTestcontainers PostgreSQL database wealth_pulse_test: registration, JWT, persistence, user isolation, deletion protection, and malformed tokens.
Frontend unit/componentVitest and React Testing Library: authentication form behavior and finance/portfolio calculation utilities.
BrowserPlaywright: mocked deterministic registration, asset workflows, detail views, and calculator interaction.

The repository currently contains five backend unit-test classes, one backend integration-test class, three frontend unit-test files, and one Playwright specification with two browser tests. JaCoCo and a Postman collection are not configured in the repository and must not be reported as executed automation.

Correct Runtime and API References

  • Backend port: 8283, not 8080.
  • Database: wealth_pulse.
  • Create asset: POST /api/assets.
  • Load assets: GET /api/assets.
  • Refresh prices: POST /api/assets/refresh-prices.
  • Update quantity delta: PUT /api/assets/update-quantity.
  • Performance: GET /api/portfolio/performance.
  • There is no /api/assets/summary endpoint and no route-based /ledger page.

Required Manual Acceptance Coverage

  1. Register, log out, log in, and reject an incorrect password.
  2. Create, update, persist, and delete stock and metal positions.
  3. Verify account B cannot see or modify account A's data.
  4. Compare displayed portfolio totals with visible holdings.
  5. Exercise learning calculators and confirm valid numeric output.
  6. Repeat core flows at desktop and narrow mobile widths.

Record skipped tests honestly. A Docker-skipped Testcontainers case is not an integration pass, and mocked Playwright flows are not full-stack PostgreSQL tests.
