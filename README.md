Wealth PulseIntelligent Wealth:
An AI-Assisted Portfolio and Precious Metals Tracking ApplicationWealth Pulse is an integrated wealth tracking system designed to bridge the gap between traditional equity management and precious metals stacking. By combining real-time asset valuation with an AI-driven fiduciary advising interface, Wealth Pulse provides users with a comprehensive view of their financial health and retirement projections.

Project Overview:
Mainstream financial tools often overlook the unique metrics required by precious metal stackers, such as raw weight in ounces and spot market price tracking. Wealth Pulse fills this operational gap by:  
 Integrated Tracking: Combining stock portfolios and physical precious metal stockpiles in one dashboard.  
 Predictive Analysis: Utilizing compound interest modeling to estimate wealth accumulation based on retirement goals.  
 AI-Assisted Guidance: Leveraging generative AI to provide personalized asset models and education on complex financial instruments like call and put options.

    Technology Stack
        The application is built using an enterprise-grade multi-tier architecture to ensure reliability and scalability:
        Backend: Java Spring Boot. Provides a robust RESTful API layer and handles algorithmic computations.
        Database: PostgreSQL. Managed via Spring Data JPA for secure, persistent storage of multi-asset portfolios.
        Frontend: React (JavaScript). A single-page application providing a responsive, interactive user interface.
        AI Integration: Spring AI. Facilitates secure communication with Large Language Models for automated portfolio assessment.
